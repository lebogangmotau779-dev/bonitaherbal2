## Project Overview
Nancy Beauty Salon is a hair salon that provides hair services to customers.
WEDE2050 Portfolio of Evidence.
-Part1: Planning and Building using HTML.
-Part2: CSS styling and responsive design
-Part3: JavaScript functionality

## Website goals and objectives
- To create a professional website for Nancy beauty salon
- To provide customers with information about the salon
- To make it easier for customers to get in contact with the salon

## Target Audience
- the target audience of the salon are people who are interested in getting their hair done.

## Website Features
- A Home page introducing the salon
- A Service page showing the service offered
- An About page providing information about the salon
- An Enquiry page that allows the customer to make enquires about the salon
- A Contact page showing the contact details of the salon

## Design and User Experince
- The salon will have a clean and simple design that reflects the salon services. The website will use clear headings and suitable images.

##Technical Requirements
- HTML for designing the structure of the website
- CSS for styling and color
_ JavaScript for functionality

##Timeline and Milestones
- The salon website is expected to be developed within 2-3 weeks this includes the planning , designing and testing of the website.

##Budget
-The website will be developed with a reasonable and affordable budget covering the material that are required

##Conclusion
- The salon website will provide a user-friendly online platform where customers can learn more about the services that are offered and be able to contact the salon.
